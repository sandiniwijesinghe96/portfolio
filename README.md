# Sandini Wijesinghe | Portfolio Website

This repository contains the source code for my personal portfolio website — a showcase of my professional journey, technical expertise, and featured projects.

---

## 🧩 Overview

This portfolio is designed to provide a clear and engaging presentation of my background, skills, and selected work. It includes an integrated contact form for potential collaborations or professional inquiries.

---

## ⚙️ Tech Stack

- **Frontend Framework:** React  
- **Styling:** CSS
- **Email Handling:** Getform / Formspree  
- **Hosting:** GitHub Pages  
- **Version Control:** Git & GitHub  

---

## 🚀 Features

- Responsive, mobile-friendly UI  
- Interactive project showcase section  
- Functional contact form with validation  
- Smooth animations and modern design  
- Optimized build for fast loading and accessibility  

---
