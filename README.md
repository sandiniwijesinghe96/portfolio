## 🛠️ Setup & Run Locally
If you’d like to run this locally (or stalk my code 👀):
```bash
git clone https://github.com/sandiniwijesinghe96/portfolio.git
cd portfolio
npm install
npm start
````

The app should now be running on `http://localhost:3000/` 🎉

---

## 🧠 Deployment

Deployed using **GitHub Pages**.

To rebuild and deploy:

```bash
npm run build
npm run deploy
```
